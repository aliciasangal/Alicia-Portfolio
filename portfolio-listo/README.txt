PORTFOLIO — INSTRUCCIONES DE PUBLICACIÓN

La página principal (index.html) redirige a:
https://aliciasangal.github.io/Alicia-Portfolio/

Los proyectos incluidos en este paquete siguen disponibles mediante sus rutas directas:
- projects/buildmypc/
- projects/helpdesk/

Para publicar en GitHub Pages:
1. Sube el contenido de esta carpeta a la raíz del repositorio.
2. En GitHub, abre Settings > Pages.
3. En Build and deployment, selecciona Deploy from a branch.
4. Selecciona la rama main y la carpeta /(root), y guarda.
