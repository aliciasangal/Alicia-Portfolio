PORTFOLIO — CÓMO ABRIRLO

1. Descomprime la carpeta.
2. Abre una terminal dentro de la carpeta portfolio-listo.
3. Ejecuta: python -m http.server 8000
4. Abre en el navegador: http://localhost:8000/

Proyectos incluidos:
- BuildMyPC: http://localhost:8000/projects/buildmypc/
- Helpdesk TI: http://localhost:8000/projects/helpdesk/

Estas son direcciones locales para probar en tu ordenador, no URLs públicas. Para compartir con reclutadores tendrás que publicar la carpeta en un hosting estático (por ejemplo GitHub Pages, Netlify o Vercel).
